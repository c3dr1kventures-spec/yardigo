📍 Door YardiGo verzameld
—
Hier plaats je evenementen (rommelmarkten, vlooienmarkten, braderies, kerstmarkten, rommelroutes) op basis van openbare bronnen (gemeentekalenders, officiële organisator-pagina's). Niet overnemen: posters, foto's, ingekopieerde teksten van Facebook. Wel: feitelijke data (titel, datum, plaats), eigen korte beschrijving, link naar bron. Organisatoren kunnen vermeldingen claimen — claims verschijnen in de queue onderaan.

🏅 Badge-systeem — Supabase setup

Het badge-systeem slaat handmatige badges op in de profiles tabel. Voer dit eenmalig uit in de Supabase SQL Editor:

ALTER TABLE profiles ADD COLUMN IF NOT EXISTS admin_badges text DEFAULT '[]';
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS is_blocked boolean DEFAULT false;
